# Krafft in Basel

Unabhängige historische Dokumentation zur Familie Krafft aus Fahrnau und ihren Basler Verbindungen.

## Veröffentlichung

Öffentliche Domain: https://krafft-in-basel.ch/
Hosting: GitHub Pages. Die Datei `CNAME` enthält die eigene Domain.
Alle HTML-Dateien, `style.css`, `krafft-portraet.jpg`, `sitemap.xml` und `robots.txt` liegen im Stammverzeichnis des Repositories.

Nach dem Hochladen in der Google Search Console für `krafft-in-basel.ch` die Sitemap `https://krafft-in-basel.ch/sitemap.xml` einreichen.

## Quellenprinzip

Die Festschrift von 1929 trägt die frühe Familiengeschichte. Angaben zu Cardinal, Hotel und Karl Ernst Krafft sind teilweise aus einer sekundären Zusammenstellung übernommen und als solche kenntlich gemacht. Keine erfundenen Ergänzungen. Das Porträt ist bis zur gesicherten Identifikation neutral beschriftet.
