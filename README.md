# Krafft in Basel

Statische historische Dokumentation zur Familie Krafft aus Fahrnau und ihren Basler Verbindungen.

## Veröffentlichung
Alle HTML-Dateien und `style.css` in das Stammverzeichnis des GitHub-Repositories hochladen. `index.html` ist die Startseite.

Die Dateien bleiben bis zur Domainregistrierung im Dezember 2026 auf `noindex,nofollow`. Vor der öffentlichen Veröffentlichung diese Metaangabe auf `index,follow` ändern und die endgültige Domain als Canonical ergänzen. Datenschutz und externe Links prüfen.

## Quellenprinzip
Die Festschrift von 1929 trägt die frühe Familiengeschichte. Angaben zu Cardinal, Hotel und Karl Ernst Krafft sind teilweise aus einer sekundären Zusammenstellung übernommen und als solche kenntlich gemacht. Keine erfundenen Ergänzungen.
